# 连接本机 Codex

## 安装时确认，也可稍后连接

1. 安装向导只查找本机 Codex 程序。发现后询问 **是否连接 Codex 作为 Solevia 内核？（推荐）**，默认不勾选；明确勾选后才启动登录与连接检查。不复制密钥，也不修改全局 Codex 配置。
2. 额外能力默认全部不选。基础 Python / Node 与应用依赖仍需安装，普通 Codex / API 对话无需下载本地大模型。安装选项会显示所选磁盘的可用空间，并按容量上限预留临时解压空间。
3. 未发现 Codex，或选择暂不连接，也能安装基础工作台。此时可以查看界面、管理手动任务；发送消息会显示小叹号，提示先连接 Codex 或配置 API，**不会生成模拟回答**。

尚未安装 Codex 时，可在安装向导打开[官方安装指南](https://learn.chatgpt.com/docs/cli)，完成安装及登录后，在网页 **模型连接 → Codex → 检测并连接** 中确认接入，无需重新安装 Solevia。自定义路径可通过启动环境的 `SOLEVIA_CODEX_EXECUTABLE` 指定。

已有安装在修复、补装能力及更新时保留当前连接和能力勾选。明确取消 Codex 连接会撤回安装器保存的连接许可；之后仍可主动连接。API 配置和两种内核共用的业务记录均保留。

## 后续补装能力

网页 **本地用户 → 模型连接 → 补装与管理能力 → 选择要安装的能力**，直接勾选文档、联网、图片识别或语义查找。页面显示安装盘可用空间和建议预留空间，可选择直连 / 系统代理、国内镜像 / 官方源，然后点击 **确认并开始补装**。无需寻找 EXE 安装窗口。

补装期间业务服务暂停，独立的本机安装服务继续向当前网页提供步骤、耗时、传输流量和下载网速；详细日志默认收起。已知文件总大小时显示真实百分比；第三方工具未报告总大小时显示活动进度，不生成虚假百分比。网速统计包含加密传输开销，校验、解压、构建或缓存复用阶段可以为 0。安装完成后点击 **返回工作台继续**，原有目标、资料和对话保留。失败时查看日志，切换网络或来源后可复用缓存重试。

本机桌面工作台需要保持运行，以提供独立安装服务。若提示尚未就绪，重新打开 `Solevia.exe` 后回到网页重试。桌面 **补装与管理能力** 仍保留为备用入口。

桌面会询问是否暂停服务；确认后勾选需要的联网、文档、OCR 或语义查找能力。安装前检查安装盘与系统临时盘容量，空间不足时提示所需容量及当前剩余量。完成后自动恢复服务，回到网页刷新即可继续使用。下载失败可保留目录、切换来源或网络模式后重试，已有文件与缓存会复用；取消勾选只停用，不自动删除文件。

## 第一次打开，接下来做什么

打开网页，点击左下角 **本地用户 → 模型连接**。未配置 API 或 Codex 连接失败时，侧栏也会出现直接进入连接设置的入口。状态卡显示当前选择与是否完成配置，选择框改选后不会立即切换。

- **Codex**：先在同一个 Windows 用户下安装 Codex，再打开 Codex 登录。命令行用户可运行 `codex login`，按[官方登录说明](https://learn.chatgpt.com/docs/auth)完成浏览器流程。然后在网页点击 **检测并连接**，检查通过后启用 Codex 内核。刷新状态只查询结果，不会主动启动 Codex。
- **自配置 API**：填写服务商基础地址（通常包含 `/v1`，不附加 `/chat/completions`、`/responses` 或 `/models`）、API Key，读取模型列表或手动填写准确的模型 ID，然后保存并使用。保存操作不会发起付费生成；发送一句简短消息可验证实际调用。列表可读取不代表列表中的每个模型都获得授权。

### 看到提示后如何处理

| 提示或状态编号 | 下一步 |
|---|---|
| `CODEX_CONSENT_REQUIRED` 尚未连接 | 用户尚未同意连接；点击「检测并连接」开始检查 |
| `CODEX_NOT_FOUND` 未找到程序 | 安装 Codex；已有安装时确认使用同一 Windows 用户，自定义位置设置 `SOLEVIA_CODEX_EXECUTABLE`，再点击「检测并连接」 |
| `CODEX_LOGIN_REQUIRED` 尚未登录 | 在 Codex 完成登录，再点击「检测并连接」 |
| `CODEX_ACCESS_DENIED` 程序启动被拒绝 | 查看程序访问权限或安全软件的具体拦截记录，处理后点击「检测并连接」，不要直接关闭安全软件或沙箱 |
| `CODEX_START_TIMEOUT` 启动检查超时 | 先确认 Codex 自身可以正常运行，再点击「检测并连接」 |
| `CODEX_START_FAILED` / `CODEX_UNAVAILABLE` 本机连接未建立 | 检查 Codex 自身运行情况与版本，点击「检测并连接」；可复制设置页中的排查说明交给自己的 Codex |
| `CODEX_DISCONNECTED` 连接中断 | 点击「检测并连接」，再查看状态；已提交生成先查看结果再重试 |
| API 列表返回 401 / 403 | 分别检查 Key 的有效性、Key 权限及账号限制 |
| API 列表返回 404 | 核对 Base URL；部分服务商没有模型列表接口，可手动填写模型 ID |
| API 列表返回 429 / 5xx | 检查服务商额度、请求频率或服务状态，稍后重试 |
| API 列表超时或网络连接失败 | 检查服务地址、网络、代理与证书配置；无需重复保存密钥 |

界面只展示经过整理的状态与处理办法，不回显服务商原始错误正文、登录文件或密钥。Codex 本机连接检查不等于模型服务的远端可用性验证；首次成功回答才证明本次调用链路可用。

## 如何找到本机 Codex

Windows 下按以下顺序查找：`SOLEVIA_CODEX_EXECUTABLE` 指定的现有文件、`PATH` 中的 `codex.exe`、当前用户 npm 安装目录中的 Codex 原生程序、`%LOCALAPPDATA%/OpenAI/Codex/bin/*/codex.exe` 中最近更新的程序。npm 的 `.cmd` 启动脚本不会交给 shell 执行，而是定位其原生程序。

找到程序后，Solevia 启动独立的 `codex app-server --listen stdio://`，完成协议握手，再通过 `account/read` 检查登录状态。需要登录而没有账号时，会提示先在 Codex 登录，再点击「检测并连接」，不会把模型目录可读取误当成账号可用。账号检测不能证明某个模型的实际调用权限，仍需一次成功生成确认。

安装包会下载独立的 Python、Node.js 和所选依赖，不要求用户预先安装开发环境。**Codex 本身不随包安装**；没有 Codex 时，先按官方指南安装并登录，随后在网页点击「检测并连接」。仅有 Codex 桌面快捷方式、但程序不在上述可发现位置时，需要指定可执行文件路径。这里不复制其他电脑的登录文件，也不申请管理员权限。

## 生成中断与自动恢复

Solevia 会区分本机 Codex 进程连接和 Codex 到模型服务的连接，保留已校验保存的目标、路线、计划批次与执行记录。失败的当前回答不会作为完整计划保存，调整失败不会覆盖原计划。

| 情况 | 自动处理 | 用户下一步 |
|---|---|---|
| 网络断连、临时限流、模型繁忙、服务异常 | 每次模型调用最多 3 次尝试（含首次）；按约 2 秒、4 秒加随机间隔退避，服务端给出更长等待时间时遵守该时间；不超过本次等待预算 | 状态区显示下一次尝试和次数；重试用尽后检查网络、稍后重试或更换模型 |
| 本机 Codex 进程意外退出 | 已获连接许可且没有其他未清理请求时，本次调用最多自动重连一次 | 仍失败时打开模型连接，点击「检测并连接」；退出 Solevia 后不会自动重新启动 |
| Codex 自身正在恢复连接 | 等待同一次生成，不额外启动重复请求 | 等待最终结果或明确失败提示 |
| 额度耗尽、登录失效、权限不足、模型不可用 | 停止自动重试，显示具体原因 | 恢复额度、重新登录、检查访问权限、更换模型，或切换到自配置 API |
| 内容超出上下文容量 | 停止自动重试，不丢弃已确认条件强行生成 | 减少本次附件、缩小调整范围或更换上下文容量更大的模型 |
| 返回空内容或结构不完整 | 空结果有限重试；格式和字段校验另有有限修复上限 | 重试或更换模型，业务校验规则保持生效 |
| 等待或排队到达上限 | 结束等待；对于已开始的生成尝试发送中断 | 核实进度后继续；不会因暂时没有新文字就提前判定失败 |
| 中断前已发起文件操作 | 不自动重放该操作，提示结果需要核实 | 先查看文件产物与确认状态，再决定是否重试 |
| Solevia 服务重启 | 把遗留运行任务标记为中断，保留已完成结果与生成检查点 | 回到原目标继续生成，或先切换内核；不因旧任务状态一直显示生成中 |

失败提示中的 **连接设置 / 切换 API** 会打开连接设置，由用户决定下一步；系统不自动切换到可能计费的 API，也不自动更换模型。配置并启用 API 后，在原目标点击 **继续生成计划**，从已保存进度补齐缺失部分，当前尚未完成的模型输出需要重新生成。运行中的请求及退避等待期间禁止切换；明确失败并清理后即可切换。

未知错误会显示安全的通用提示，保留当前数据供检查与手动重试，不把服务商原始报错、私有地址、密钥或本地路径展示给用户。错误类型参考 [Codex App Server 官方协议](https://learn.chatgpt.com/docs/app-server)；本机的模型访问权、额度及恢复时间以实际账号与服务返回为准。

## 连接需要哪些权限

Solevia 使用 [Codex App Server](https://learn.chatgpt.com/docs/app-server) 的本地标准输入输出连接，界面中的对话直接交给 Codex 处理。规则与任务引导随应用放在隔离工作区中，不需要安装到全局 skill 目录，也不需要用户手动配置 MCP 服务器。

| 操作 | 当前边界 |
|---|---|
| 安装 Solevia | 当前用户目录，无需管理员权限；首次下载依赖需要联网 |
| 连接 Codex | 查找程序，启动独立进程，沿用 Codex 登录；不复制认证、不改全局配置 |
| 读取资料 | 用户在 Solevia 导入的资料按目标和固定版本提供；不是开放整个磁盘 |
| 修改附件 | 原件只读，先在原对话选择允许或拒绝，再生成独立修改版 |
| 运行命令、编辑原目录、扩大权限 | 当前版本不开放，模型请求不会被自动放行 |
| 联网搜索 | 使用 Codex 配置支持的原生搜索；组织策略、账号与网络限制仍可能影响可用性 |

普通对话不需要每次重复授权。首次登录、企业策略或当前版本未支持的操作可能需要用户处理；不会为了减少提示而关闭沙箱或授予完全访问。Codex 的[沙箱与审批机制](https://learn.chatgpt.com/docs/agent-approvals-security)继续生效。

## 想让自己的 Codex 帮忙检查

安装向导里可直接 **复制排查指令**，再粘贴到自己的 Codex：

> 请帮我检查本机 Codex 是否已安装并完成登录，确认 codex app-server 可以启动，然后在 Solevia 的模型连接中选择本机 Codex。不要读取或复制登录密钥，不要关闭沙箱，不要授予整个磁盘权限，不要修改全局配置。需要安装、登录或改动设置时先向我说明。

这是可选的故障排查方式。正常接入由 Solevia 完成。单独安装一个 [skill](https://learn.chatgpt.com/docs/build-skills) 可以提供规则与引导，网站与 Codex 之间的连接仍需要应用内适配器。
