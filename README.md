## 让目标有方向，让每天有着落

想学一项新技能，准备一场考试，完成一个作品，或把生活安排得更从容——把想法告诉 Solevia，和它一起找到适合自己的行动路线。

Solevia 会通过对话了解你的目标、基础、时间和偏好，把想法整理成清晰的阶段与任务。开始之后，你仍然可以随时提问、反馈困难、调整安排，让规划跟着实际进展继续向前。

- **懂需求**：从目标、顾虑和期待开始聊，逐步理清你想完成什么。
- **会规划**：把方向拆成阶段、成果和行动，兼顾时间、节奏与先后顺序。
- **能互动**：从最初构想到执行复盘，每一步都可以继续讨论。
- **易执行**：重点任务、日历安排、专注计时和进度记录集中在同一工作区。
- **可调整**：忙起来、卡住了、想换方向，都能结合已有进展重新安排。
- **懂先后**：逐份练习与订正、每周训练与复盘、整组成果与验收，按真实前提衔接，让能推进的行动及时开始。

## 三种规划方式，找到适合你的步调

不同目标，需要不同的推进方式。Solevia 支持节奏型、探索型和期限型规划，让日常坚持、兴趣尝试与重要交付各有合适的安排。

| 规划方式 | 适合什么目标 | Solevia 如何帮你推进 |
|---|---|---|
| **节奏型 · 稳稳积累** | 语言学习、阅读训练、运动习惯、持续技能练习 | 围绕重复频率安排任务，把阶段成长融入日常；结合完成情况调整节奏 |
| **探索型 · 边做边找到方向** | 兴趣入门、职业方向尝试、阳台绿植、个人创作与开放式项目 | 先安排一次有收获的尝试，设置可观察的成果和回顾点，再根据体验展开下一阶段 |
| **期限型 · 朝重要日期前进** | 考试备考、求职申请、项目交付、作品提交与活动筹备 | 从截止日期倒排阶段，协调任务依赖、固定日程和可用时间，让准备过程更清楚 |

你可以先探索，再系统投入；也可以让阶段成果与固定练习相互配合。Solevia 会根据讨论推荐合适的方式，和你一起决定如何开始。

![探索型规划：围绕观察成果、行动条件与阶段检查点展开](docs/assets/solevia/exploration.webp)

*先收获一次具体体验，再决定下一步走多远。*

## 从一句想法，到清晰的行动路线

### 聊清楚，才更合适

“我想学 Agent 开发，但不知道先学什么。”

从这样一句话就能开始。Solevia 会结合你的已有基础、期待成果与日常投入继续追问，把零散想法整理成目标摘要。你可以边聊边补充、纠正和收敛范围，让后续规划贴合自己的需要。

![目标讨论与需求笔记：对话、基础、投入和预期成果同时呈现](docs/assets/solevia/clarification.webp)

*想法留在对话里，关键需求整理在身边。*

### 看得懂路线，也知道为什么这样安排

先看清阶段方向，再展开具体行动。每个阶段都有对应的目的与产出，学习、练习和成果之间的关系一目了然。你可以继续讨论路线、调整重点，让时间花在更有价值的事情上。

![阶段路线：从起点到成果，呈现每一步的目的与产出](docs/assets/solevia/route.webp)

*知道先做什么，也理解这一步通向哪里。*

### 把安排放进你的生活

课程、会议、休息和日常事务，都可以成为规划的时间依据。Solevia 将固定时段与弹性任务一起考虑，结合实际可用时间安排阶段任务；有明确期限的目标，还可以围绕重要日期向前倒排。

![计划审核：阶段任务、时间安排与需求依据并排展示](docs/assets/solevia/plan.webp)

*从“想完成这些事”，走到“这段时间可以这样做”。*

### 多步任务，也能衔接清楚

每套题做完后订正对应试卷，每篇文章写完后审阅对应内容，每周训练后复盘当周记录——Solevia 能围绕同一对象或同一周期组织前后步骤。需要整体验收时，也能把全部成果汇集到最后一步。

任务分段、跨周或改期后，关联仍跟着原本的任务走。你可以逐项推进，在该等待时保留前提，在可以开始时接上下一步。

## 开始之后，Solevia 依然在你身边

### 今天做什么，打开就知道

工作台汇集长期规划与轻量安排，突出眼前值得推进的任务。进入执行页，查看今日行动与日历，用专注计时进入状态，记录部分投入或完成成果。每一次行动，都成为后续规划的依据。

明亮的暖色任务卡片把行动、预计投入和完成产出放在一起。开始、完成和记录部分进度触手可及；改期、跳过与困难反馈也有清楚的入口。提醒与周期进度收在一条轻量提示栏中，想看时展开，让今天要做的事始终站在前面。

![每日执行：暖色任务卡片、明确的行动与产出，以及随手可用的进度操作](docs/assets/solevia/execution.webp)

*先看清今天的一步，再轻松开始。*

### 日历里看安排，也看走过的每一天

执行日历将固定日期与建议执行日区分呈现，完成、部分完成和待处理记录都能找到对应位置。点击日期回看当天任务，结合阶段与整体进度了解自己的步调，也可以继续调整后续安排。

<p align="center"><img src="docs/assets/solevia/calendar.webp" width="400" alt="执行日历：日期安排、完成状态与执行记录" /></p>

*安排有位置，进展有痕迹。*

### 打开番茄钟，把注意力留给眼前的事

可以直接按今日任务的建议时长开始，也可以选择自己的专注节奏。全屏专注用轻柔的玻璃背景收起干扰；退出全屏后计时继续，随时回到任务、查看资料或与 Solevia 讨论，再一键回到专注。结束后记录实际投入，让每一小步都留下回响。

![全屏番茄钟：专注倒计时、暂停与记录，退出全屏后继续计时](docs/assets/solevia/focus.webp)

*一次做好一件事，慢慢走到想去的地方。*

### 随时提问，带着上下文一起想

“这个概念怎么理解？”“这一步卡住了怎么办？”“今天只能投入一小段时间，先做什么？”

Solevia 可以结合目标、计划和实际进度继续交流，帮助你理解任务、梳理困难、寻找下一步。值得保留的执行心得可以融入后续讨论，让协作随着使用逐渐深入。

![执行中的持续对话：结合当前任务讨论问题与行动建议](docs/assets/solevia/discussion.webp)

*提问、理解、行动，顺着同一个目标继续。*

### 有变化，一起重新安排

临时有事、任务延期、练习太难，或对目标有了新的想法，都可以直接告诉 Solevia。它会结合已有进展梳理调整建议，让你查看影响、确认变化，再继续推进。暂停、恢复、补做和复盘，也都能在同一条规划中衔接。

![调整预览：查看建议、理解变化并确认新的安排](docs/assets/solevia/adjustment.webp)

*规划留有弹性，已经走过的每一步都有记录。*

## 开始使用 Solevia

**下载、安装、连接模型，就可以开启第一步。**

1. 在[下载页面](https://github.com/yqf66/Solevia/releases/latest)选择 **Solevia-Setup-0.1.6-windows-x64.exe**，双击打开中文安装向导。
2. 选择安装位置和需要的能力，看清用途与占用后确认安装。向导会自动准备运行环境、依赖和工作区，无需预先安装 Python 或 Node.js。
3. 点击桌面上的 **Solevia**，工作台自动在浏览器中打开。在「模型连接」中填写自己的服务地址、模型名称与 API 密钥，就能开始讨论目标。

![中文安装向导：选择能力、了解用途与占用，确认后自动准备环境](docs/assets/solevia/installer.webp)

选择好能力、下载源和网络模式，就可以开始安装。向导会显示当前步骤；文件下载提供进度条、已下载大小、速度与预计剩余时间，下载较慢时给出等待提示。

![实际安装过程：查看当前步骤、文件下载进度和实时速度](docs/assets/solevia/install-progress.webp)

日常使用无需保留命令行窗口。Solevia 在后台管理服务，关闭管理窗口后留在系统托盘；随时重新打开工作台、检查更新或退出。熟悉脚本的用户仍可选择 ZIP 版本。

EXE 内置安装工具，默认直连并提供国内镜像；下载时显示进度、速度与错误排查提示。首次安装仍需联网获取运行环境与所选依赖。目前提供 Windows 64 位安装包；完整步骤见[安装与使用指南](START_HERE.md)。

| 想做什么 | 图形入口 |
|---|---|
| 安装 Solevia | 下载并打开 **Solevia-Setup** 安装程序 |
| 打开工作台，开始今天的安排 | 桌面或开始菜单中的 **Solevia** |
| 结束当前工作区的服务 | 管理窗口或托盘中的 **退出 Solevia** |
| 查看新版，确认后更新 | 管理窗口或托盘中的 **检查更新** |
| 补装联网、文档、文字识别或语义检索 | 管理窗口中的 **管理能力** |

Solevia 采用本地优先的工作方式，让规划、资料与执行记录在自己的工作区中持续积累。

安装器按需准备联网阅读和本地模型组件；已有 Edge 或 Chrome 时直接使用，其他浏览器组件由安装器准备。启动后自动守护服务，有新版时提示你确认更新，个人设置、资料与执行记录继续保留。

## 系统要求与按需安装

Windows 10 / 11 64 位（x64），使用当前版本 Edge、Chrome 或 Firefox。首次安装需要联网，安装器自动准备运行环境。建议至少 4 GiB 内存；同时启用图片识别或语义查找时建议 8 GiB 以上，并按下面的增量预留空间。

| 能力 | 预计下载 | 磁盘增量（含缓存） | 使用时额外内存 |
|---|---|---|---|
| 基础工作台 | 150–350 MiB | 700 MiB–1.5 GiB | 约 0.3–1 GiB |
| 联网查资料 | 150–450 MiB | 500 MiB–1.4 GiB | 约 0.5–1.5 GiB |
| PDF / Office 文档 | 40–150 MiB | 150–500 MiB | 约 0.1–0.5 GiB |
| 图片与扫描文字识别 | 80–300 MiB | 200–800 MiB | 约 0.3–1 GiB |
| 语义查找 | 600 MiB–3 GiB | 2–8 GiB | 约 1–3 GiB |

容量是安装前估算，受已有缓存、依赖和资料影响；建议再留 2 GiB 临时解压空间。内存与磁盘大小是不同指标，安装向导会随选择汇总容量。在线对话使用你连接的模型服务，无需在本机运行对话大模型。

## 数据与隐私

规划与资料保存在安装目录的 `user-data/`。使用在线模型时，问题与相关对话、规划或资料片段会发送给你选择的模型服务商；联网检索会向搜索引擎提交查询并访问目标网页。Windows 模型密钥使用当前用户加密保存。详见 [隐私与数据流向](PRIVACY.md)。
